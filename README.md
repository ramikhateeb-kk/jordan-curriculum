# رفيق المنهاج الأردني المطور - المعلم الذكي
## Jordan Curriculum AI Assistant & Question Solver

مشروع متكامل ومطور لدعم الطلبة والمعلمين في المملكة الأردنية الهاشمية لمناهج وزارة التربية والتعليم لكافة الصفوف (من الأول الأساسي وحتى الثاني ثانوي / التوجيهي).

### التحديثات والتحسينات المعتمدة:
1. **تنسيق عرض الشرح واتجاهه للغة الإنجليزية (LTR):**
   - تم ضبط كافة شروحات وتمارين وقواعد ومفردات مادة اللغة الإنجليزية (Action Pack) لتعمل بنظام `Left-to-Right` مع خط مناسب لمنع انقلاب علامات الترقيم أو اختلاط النصوص العربية بالإنجليزية.
2. **إزالة الأسطر الفارغة في نتائج كتاب الأنشطة والتمارين:**
   - تم تنظيف كافة المسافات الزائدة والفواصل الفارغة المتتالية لعرض بطاقات التمارين بشكل مباشر ومحكم.
3. **الحل والشرح الذكي التلقائي بدلاً من رسالة 'تعذر وجود إجابة':**
   - يقوم الذكاء الاصطناعي (Gemini) بالبحث وحل السؤال وشرحه خطوة بخطوة وربطه بكتاب الأنشطة وتقديم تنبيهات امتحانية.
   - لا تظهر رسالة التنبيه إلا عند سؤال الطالب عن شيء خارج اختصاص المادة تماماً (مثل السؤال عن دورة الماء في كتاب التاريخ)، مع توجيه الطالب للمادة المناسبة.

### التشغيل:
```bash
pip install -r requirements.txt
streamlit run app.py
```
