# المساعد الذكي للمناهج الأردنية (Jordanian Curriculum AI Assistant)

منصة تعليمية متكاملة لخدمة المعلمين والطلبة في المملكة الأردنية الهاشمية وفق مناهج وزارة التربية والتعليم المعتمدة.

## المميزات الرئيسية وتعديلات تبويب "اشرح لي":
1. **تنسيق مخصص للغة الإنجليزية (LTR Layout & Typography):**
   - دعم كامل لاتجاه النص من اليسار لليمين (LTR) لشروحات مادة اللغة الإنجليزية (Action Pack) لضمان سلامة علامات الترقيم والأقواس وترتيب الجمل الإنجليزية وقواعدها.
   - خيار تبديل الاتجاه يدوياً بين LTR و RTL.
   - نطق صوتي للكلمات والجمل الإنجليزية.
2. **إزالة الأسطر الفارغة الزائدة في كتاب الأنشطة:**
   - تنظيف ومعالجة مخرجات البحث في كتاب الأنشطة والتمارين (Activity Book) لعرض النتائج بشكل أنيق ومضغوط وبدون أسطر فارغة متكررة.
3. **الحل والشرح الذكي لجميع الأسئلة والصفحات:**
   - عند طلب الطالب حل أي سؤال أو تمرين برقم الصفحة، يقوم النظام بحله وشرحه بالتفصيل بالذكاء الاصطناعي دون إظهار رسالة "تعذر وجود إجابة".
   - لا تظهر رسالة تعذر الإجابة إلا في حالة واحدة فقط: إذا كان السؤال خارجاً كلياً عن المنهاج والمادة المختارة (مثل السؤال عن دورة الماء في الطبيعة أثناء اختيار مادة تاريخ الأردن).

## تشغيل النظام:

### 1. تشغيل تطبيق بايثون (Streamlit):
```bash
pip install -r requirements.txt
streamlit run app.py
```

### 2. تشغيل تطبيق الويب (React / Vite Full-Stack):
```bash
npm install
npm run dev
```
